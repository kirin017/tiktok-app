Privacy Policy

Last updated: October 25, 2026

Agentic AI Studio ("the app") is a personal tool used only by its operator. It does not serve other users.

Data the app accesses

  • Basic TikTok profile information of the operator (open ID, display name, avatar), via the user.info.basic scope.
  • An access token used to upload or publish the operator's own videos, via the video.upload and video.publish scopes.

How data is stored

Access tokens are stored only on the operator's own computer. The app has no server and no database. It does not collect data from other TikTok users, and it does not sell or share any data.

This website

This website is a static page hosted on GitHub Pages. The authorization callback page shows the authorization code in the browser only. It does not send the code anywhere. GitHub may keep standard server logs; see GitHub's privacy statement.

Revoking access

The operator can revoke the app's access at any time in TikTok: Settings and privacy → Security → Apps and services.

Contact

Questions: open an issue at github.com/kirin017/tiktok-app.
